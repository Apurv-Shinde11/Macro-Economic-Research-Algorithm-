Motion & type tokens

Written to extend past Sentinel unchanged: Atlas, PE Intel and Geopolitical Watch import the same custom-property block and the same .reveal / ring-draw / count-up / pulse mechanics, and swap in their own content. Only --font-* and the honesty-state colors are surface-specific by design.

/* motion — identical across every surface */ --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1); --dur-reveal: 760ms; /* section stagger-in */ --dur-ring: 1400ms; /* confidence ring draw + count-up */ --stagger-step: 90ms; /* per-item delay in a reveal group */ /* typography — the swappable half */ --font-display: 'Cormorant Garamond' | 'Newsreader'; --font-body: 'DM Sans' | 'Archivo'; --font-mono: 'JetBrains Mono' | 'IBM Plex Mono'; @media (prefers-reduced-motion: reduce) { .reveal, .why-card, .live-dot { animation/transition: none } }
